## 双ISP 到底是什么，哪些说法是营销

三个概念经常被混着用，先把它们拆开：

- **原生 IP**：IP 的注册地和机房物理位置一致。洛杉矶机房的 IP，在 WHOIS 里的国家是美国。
- **住宅 IP / 家宽 IP**：IP 归属的 ASN 是 Comcast、AT&T、Cox 这类民用宽带运营商，而不是数据中心。
- **双 ISP**：同一个 IP 在两个不同民用 ISP 名下都有注册记录。

平台风控查的是 ASN 归属。机房 IP 的 ASN 一看就是 IDC，被判成非真人流量，轻则限流、重则封号；住宅 IP 在这一层看起来像普通美国家庭宽带。双 ISP 多出来的一层意义是容错：其中一个 ISP 的段被批量标记时，另一个还能撑一阵。

**双 ISP 不等于两个 IP。** WePC 美国线每条套餐的参数里都写着 `IPv4 X 1`，只给一个地址，只是这一个地址挂在两家 ISP 名下。需要多个 IP 得单独加购，别指望买一条套餐拿到两个干净地址。

**双 ISP 是 IP 属性，9929 是线路属性，两者互相独立。** WePC 把这几种组合拆开卖：4837 家宽、9929 家宽、9929 高配，价格差异来自线路和硬件，不来自 IP 属性。

## 下单前必须确认的 5 件事

**1. 当前分配的是哪个 IP 段。** IP 段会随补货更换，页面不会实时显示。开工单问：“这条套餐现在分配哪个段，是否双 ISP 属性，能否指定段。”问清楚再付钱，比买完发现段不对再折腾省事。

**2. 流量是双向计算的。** 1.5TB 是上传加下载合计，不是单向。做视频上传的人消耗速度会比预期快很多，一条 500MB 的素材传 3000 次就满了。

**3. 超流量后限速 3Mbps，不停机。** 3Mbps 能干什么：文字网页、SSH、API 调用、收邮件，都行。不能干什么：直播推流、4K 视频、大文件传输。这个规则比“超流量停机”友好，但别把它当成不限量。

**4. 退款是原路还是退余额。** 3 天内或累计用量不超过 10GB 可申请原路退款，超出后按比例退到账户余额且不可提现。这是公开信息里的表述，你下单时的实际条款以结算页为准，付款前扫一眼。

**5. 内存只有 512MB。** Linux 跑代理、跑轻量脚本、跑网页版后台没问题。要装 Windows、要跑编译、要开多个浏览器实例，直接看 6GB 那条，别在 512MB 上折腾。

## 常见问题

**双ISP 和原生 IP 是一回事吗？**

不是。原生 IP 只说明注册地在美国，归属仍可能是数据中心。双 ISP 住宅 IP 要求归属是民用宽带运营商，并且在两家 ISP 名下都有记录。跑 ChatGPT 这类只查地区归属的服务，原生 IP 就够；跑 TikTok、做社媒矩阵，双 ISP 住宅属性的差别才明显。

**9929 一定比 4837 快吗？**

不一定“快”，是“稳”。两者带宽在这家都是 200Mbps，日常下载速度看不出差别。差别在晚高峰的丢包率和延迟抖动，9929 更小。如果你的使用时段集中在国内晚上八点到十一点，这 3 澳元值得花；如果主要在北京时间白天用，4837 完全够。

**512MB 内存能跑 TikTok 直播推流吗？**

推流软件本身吃内存不多，OBS 这类工具在低码率下 512MB 能跑起来，但同时开浏览器登录后台就会紧张。要长期稳定直播，建议直接上 9929 那两条（同样是 512MB，但线路稳），或者用本地电脑推流、VPS 只做网络出口。

**韩国、日本节点能直连吗？**

页面上写得很清楚：韩国“联通绕路，直播建议中转”，日本有一条明确标“无优化，需要中转”。只有 AUD$49.90 那条日本直播专线写了“无需中转”。买之前看清楚这一行字，别默认亚洲节点就一定直连快。
